# Java-Data-Structure-Suite
A comprehensive suite of generic data structures created to explore algorithm efficiency, abstraction, and interface implementation. Includes multiple linked-list versions (Q1–Q3) demonstrating refinement and feature expansion.

Key Features

Implemented multiple generic singly linked list classes with iteration support.

Integrated custom List and Iterator interfaces.

Explored abstraction, inheritance, and generics in object-oriented Java.

Full CRUD-style operations and traversal comparable to Java’s native collections.

Technologies

Java

Generics, Iterators, Interfaces

Object-oriented design
